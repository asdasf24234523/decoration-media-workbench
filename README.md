# 装修新媒体协同工作台（本地网页版）

## 如何运行
方式一（最简单）：双击 `index.html` 用浏览器打开即可。
方式二（推荐，避免个别浏览器限制 localStorage）：在 workbench 目录起一个本地服务
```
cd workbench
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能模块
1. **短视频记录** — 日期/发布平台(多选)/视频数量/投流金额/客资线索数
2. **直播记录** — 直播日期/场次/投流金额/客资线索数
3. **客资线索库** — 来源(短视频/直播间)/客户信息/分配对象/跟进状态/跟进记录时间线
4. **数据看板** — 日期区间筛选，自动汇总：短视频发布数&投流、直播场次&投流、各来源客资、销售排名、留资对账
5. **导出Excel** — 勾选导出字段 + 合计行带 `SUM()` 公式（打开Excel自动求和，非写死）
6. **人员管理** — 维护销售/分配对象名单

## 数据存储
- 全部存在浏览器 localStorage（key: wb_sv / wb_live / wb_leads / wb_staff）
- 提供「数据备份JSON」导出/导入，换电脑或清缓存前建议备份
- ⚠️ 当前为单机版：数据仅在本机本浏览器。要真正多人实时协同，需接后端服务（见设计文档 v1.0）

## 关于"多人协同"的说明
本次按你要求先做本地版（数据存储至本地浏览器）。真正的跨人多端同时录入/查看，需要：
- 前端不变，后端改用 Node + MySQL（已规划，见 `装修行业新媒体协同工作台_产品设计文档_v1.0.md`）
- 权限：新媒体可录入客资、主管可分配客资、销售仅看自己客户（RBAC 已实现于设计文档）
